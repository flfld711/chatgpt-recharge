## 国内用户付款失败，到底卡在哪

按大家实际遇到的情况，失败原因基本逃不出这几种：

1. **银行卡不支持海外订阅。** 国内银联卡、借记卡、不少虚拟卡都无法完成 OpenAI 的周期扣款。有些卡能在别的海外网站付款，不代表能订阅 ChatGPT。
2. **账单地址填错。** Billing Address 不是随便编一个国外地址就行，地址、邮编、国家要和卡片信息对得上，对不上直接被拒。
3. **银行风控。** 部分银行会主动拦截美元订阅和国际自动续费，卡里有钱也照样失败。
4. **反复试卡。** 一次失败就换卡、换地址、换浏览器、换网络，支付系统看到异常尝试太多，拦截只会更狠。越试越难成功，这不是玄学。
5. **退而求其次买共享号。** 便宜是真便宜，但多人挤一个账号，随时被挤下线，聊天记录、上传的文件和隐私都没法控制。

前三条决定了大部分人没法直接走官方订阅，官方渠道也不支持支付宝和微信——所以才有了后面这些替代路子。

不同平台界面略有差别，流程大同小异：

2. **选购套餐并付款，拿到卡密。** 卡密截图保存好，不要泄露给别人。
3. **自己登录 ChatGPT，获取授权 Token。** 在已登录的浏览器里打开会话信息页面，会看到一段 JSON 格式的内容，Ctrl+A 全选、Ctrl+C 复制。这是整个流程里失败率最高的环节。

5. **回 ChatGPT 验证是否到账。**

> Token 复制不完整是代充失败的头号原因。那串内容一个字符都不能少，很多人充值失败不是卡密有问题，而是复制时漏了开头或结尾。
